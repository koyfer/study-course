Bash: скрипти, змінні, умови, цикли та функції

Bash — «клей» між утилітами Linux. Він є майже на кожному сервері, тому deployment-скрипти й автоматизацію рутинних дій найчастіше пишуть саме на ньому.

Чого ви навчитесь#

  • Створити і запустити bash-скрипт (shebang, права, позиційні параметри).
  • Правильно працювати зі змінними: присвоєння без пробілів, різниця "подвійних" і 'одинарних' лапок.
  • Використовувати спецзмінні $0 $1 $# $@ $? $$ та підстановку команд.
  • Писати умови if [ … ] з правильними операторами для чисел і рядків.
  • Писати цикли for, while, until і функції з local-змінними.

Оболонки і чому bash#

Shell (оболонка) — програма, що приймає ваші команди і запускає їх. У Linux є багато оболонок: sh (Bourne), csh, ksh, tcsh, zsh, але найпопулярніша — bash (Bourne Again Shell). Вона сумісна з sh, взяла найкраще з ksh і csh та відповідає стандарту POSIX.

Bash чи Python?

Питання з чату лекції. Bash «склеює» POSIX-утиліти (grep, cp, systemctl…) і є майже в будь-якій системі, а Python може бути не встановлений (у мінімальних образах на кшталт Alpine навіть bash буває відсутній — там sh). Для коротких сценаріїв розгортання — bash, для складної логіки й обробки даних — Python.

Перший скрипт#

Перший рядок — shebang #!/bin/bash: він каже ОС, яким інтерпретатором виконувати файл.

#!/bin/bash
# hello.sh — коментар починається з #
name="DevOps"
echo "Hello, $name! Сьогодні: $(date +%F)"
chmod +x hello.sh     # дати право на виконання
./hello.sh            # запуск із поточного каталогу
bash hello.sh         # або явно через інтерпретатор

Змінні та лапки#

  • Змінні не оголошуються — створюються при присвоєнні. Значення завжди зберігаються як рядки; арифметика перетворює їх на числа.
  • Присвоєння — без пробілів навколо =: count=0. Звернення — через $: $count або ${count}.
  • Тип не фіксований: count=0, потім count=Sunday — легально, але погана практика. Одна змінна — один тип даних.
  • \ — символ екранування: зберігає буквальне значення наступного символу (\$ виведе знак долара).

"Подвійні лапки"

Змінні підставляються.

var="test string"
echo "Value: $var"
# Value: test string

'Одинарні лапки'

Усе буквально, без підстановки.

var="test string"
echo 'Value: $var'
# Value: $var

Рядки з пробілами чи спецсимволами обов'язково беріть у лапки. Ввести значення з клавіатури — команда read:

read -p "Введіть ім'я: " user
echo "Привіт, $user"

Змінні середовища

Є локальні змінні (лише в поточній оболонці) і змінні середовища (environment), які задає система і успадковують дочірні процеси. Перелік — команда env; створити свою — export NAME=value.

ЗміннаЩо містить
PATHСписок каталогів через :, де шукаються команди
HOME, PWDДомашній і поточний каталог
USER, LOGNAMEПоточний користувач
HOSTNAME, SHELLІм'я машини, шлях до оболонки
PS1Вигляд запрошення: \u користувач, \w каталог, \W його остання частина, \t час, \d дата, \$ символ запрошення

Ініціалізаційні файли: /etc/profile, /etc/profile.d/, ~/.bash_profile (login-оболонка), ~/.bashrc і /etc/bashrc (інтерактивна), ~/.bash_logout (вихід).

Спеціальні змінні і підстановка команд#

ЗміннаЗначення
$0Ім'я скрипта
$1 … $9, ${10}Позиційні параметри (аргументи)
$#Кількість аргументів
"$*"Усі аргументи одним рядком
"$@"Усі аргументи окремими рядками (безпечно для циклів)
$?Код завершення останньої команди: 0 — успіх, інше — помилка

#!/bin/bash
# ./args.sh one two  →  2 / ./args.sh / one
echo $#
echo $0
echo $1

Підстановка команд вставляє вивід команди у змінну. Старий синтаксис — зворотні лапки `cmd` (не плутати з одинарною лапкою!), сучасний і зручніший — $(cmd):

list=`ls -l`              # як на слайдах
files=$(ls | wc -l)       # рекомендований синтаксис, можна вкладати
echo "Файлів: $files"

Арифметика#

Вирази обчислюються через $(( вираз )) (старий варіант — $[ вираз ]) або команду let. Bash працює лише з цілими числами — дробових немає.

echo $(( 100 / 3 ))         # 33 — ціла частина!
myvar="56"
echo $(( myvar + 12 ))       # 68
myvar=$(( myvar + 1 ))       # інкремент
let COUNTER=COUNTER+1        # те саме через let

Умови: if і вирази test#

if [ "$myvar" -eq 3 ]; then
    echo "myvar = 3 як число"
elif [ "$myvar" = "3" ]; then
    echo "myvar = 3 як рядок"
else
    echo "інше"
fi

if [ -z "$1" ]; then echo "Порожній параметр"; exit 1; fi
Синтаксис

[ — це команда, тому пробіли обов'язкові: після [, перед ] і навколо операторів. [ $a -eq 1 ] ✓, [$a -eq 1] ✗. Якщо then/do на тому ж рядку — перед ним ставте ;.

ПорівнянняЧислаРядки
дорівнює / не дорівнює-eq / -ne= або == / !=
більше / більше або рівно-gt / -ge> (за алфавітом)
менше / менше або рівно-lt / -le< (за алфавітом)
довжина > 0 / = 0—-n str / -z str

Також є файлові оператори: -d (це каталог), -f (звичайний файл), -e (існує), та логічні: !, &&, ||.

Цикли#

ЦиклВиконуєтьсяПриклад
for … inдля кожного елемента спискуфайли, аргументи, сервери
whileпоки умова істинналічильник, читання рядків
untilпоки умова хибна (до моменту, коли стане істинною)чекати, поки сервіс підніметься
for x in one two three; do
    echo "number $x"
done

for f in /etc/r*; do                 # перебір файлів за маскою
    if [ -d "$f" ]; then echo "$f (dir)"; else echo "$f"; fi
done

COUNTER=0
while [ $COUNTER -lt 10 ]; do        # 0..9
    echo "The counter is $COUNTER"
    COUNTER=$(( COUNTER + 1 ))
done

n=0
until [ $n -eq 10 ]; do              # теж 0..9
    echo $n; n=$(( n + 1 ))
done

Серед елементів мови також є select (меню вибору), функції та перехоплення сигналів trap (наприклад, прибрати тимчасові файли при Ctrl+C).

Функції та область видимості#

За замовчуванням змінні в bash глобальні: функція, що змінює myvar, змінить її для всього скрипта. Щоб змінна жила лише у функції — оголосіть її local.

Без local

myvar="hello"
myfunc() {
  myvar="one two three"
  for x in $myvar; do echo $x; done
}
myfunc
echo "$myvar / $x"
# one two three / three

З local

myvar="hello"
myfunc() {
  local x
  local myvar="one two three"
  for x in $myvar; do echo $x; done
}
myfunc
echo "$myvar / $x"
# hello /   (x порожня)

Що повертає функція? Питання з чату: return N повертає лише код завершення 0–255 (читається через $?), як у будь-якої команди. Щоб повернути дані, функція виводить їх через echo, а викликач забирає через $(…):

get_ip() { hostname -I | awk '{print $1}'; }
is_root() { [ "$(id -u)" -eq 0 ]; }    # код 0 = «істина»

ip=$(get_ip)
if is_root; then echo "root on $ip"; else echo "not root"; fi

Практика: мінімальний deployment-скрипт#

Результат курсу — уміти написати bash-скрипт розгортання. Ось шаблон, що поєднує все з лекції: аргументи, перевірки, функції, коди завершення.

#!/bin/bash
# deploy.sh <git-url> [branch]  — розгорнути сайт у /var/www/html/app
set -e                                   # зупинитись на першій помилці

REPO="$1"; BRANCH="${2:-main}"; TARGET=/var/www/html/app

log() { echo "[$(date +%T)] $*"; }

if [ $# -lt 1 ]; then
    echo "Usage: $0 <git-url> [branch]"; exit 1
fi
if [ "$(id -u)" -ne 0 ]; then
    echo "Run as root (sudo)"; exit 1
fi

if [ -d "$TARGET/.git" ]; then
    log "Оновлюю код ($BRANCH)"
    git -C "$TARGET" pull origin "$BRANCH"
else
    log "Клоную $REPO"
    git clone -b "$BRANCH" "$REPO" "$TARGET"
fi

chown -R apache:apache "$TARGET"
systemctl restart httpd
log "Готово, код завершення: $?"

Типові помилки#

name = "Ivan" — з пробілами.
Bash сприйме name як команду. Правильно: name="Ivan".
[ "$a" = 10 ] для порівняння чисел / -eq для рядків.
Числа: -eq -ne -lt -le -gt -ge. Рядки: = != -z -n. «010» і «10» рівні як числа, але не як рядки.
Змінна без лапок: [ -z $1 ], rm $file.
Якщо значення порожнє або з пробілами — синтаксична помилка чи видалення не того. Пишіть "$1", "$file".
echo $(( 7 / 2 )) дасть 3.5.
Bash рахує лише цілі: результат 3. Для дробів — bc або awk.
return "текст" поверне рядок із функції.
return — тільки код 0–255. Дані — через echo і $(func).
