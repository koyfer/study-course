# Хмарні технології та сервіси — інтерактивний конспект

Статичний навчальний сайт українською мовою: 12 лекцій курсу (3 тижні) з DevOps-основ, на яких тримаються хмарні сервіси — Linux, Bash, веб-архітектура, LAMP, мережі, хмари, IaC/Terraform, Docker, Git, CI/CD (Jenkins, GitHub Actions).

Кожна лекція розрахована на 10–18 хвилин читання і містить: цілі, ключові поняття, власні SVG-схеми, приклади команд і коду, типові помилки та тест із 7 питань.

## Можливості

- Головна сторінка з картою курсу, планом на 3 тижні і загальним прогресом.
- Сторінки тижнів і окремі сторінки лекцій зі змістом «На цій сторінці», навігацією «попередня / наступна».
- Пошук по всіх лекціях (`Ctrl+K` або `/`).
- Позначка «опрацьовано» і результати тестів — зберігаються в `localStorage` **лише в цьому браузері на цьому пристрої** (без синхронізації між пристроями).
- Світла / темна тема, адаптивна верстка для телефонів, планшетів і десктопів.

## Структура

```
index.html               головна
weeks/week-N.html         сторінки тижнів
lectures/week-N/lecture-M.html   лекції (M — наскрізний номер лекції 1–12)
css/style.css             стилі
js/course-data.js         список лекцій і пошуковий індекс (генерується)
js/progress.js            прогрес у localStorage
js/navigation.js          меню, тема, зміст, індикатори прогресу
js/app.js                 пошук, тести, кнопка «опрацьовано»
assets/icons/             іконка сайту
```

Усі шляхи відносні, тому сайт працює як GitHub Pages project site (`https://<user>.github.io/study-course/`) і локально з будь-якого статичного сервера:

```bash
python3 -m http.server 8000
```

## Джерела і обмеження

Конспекти складено з презентацій, PDF-матеріалів і чатів лекцій курсу. Оригінальні презентації, PDF, відео та аудіо в репозиторій **не** входять. Аудіозаписи лекцій не транскрибувалися, відео не оброблялися — тому пояснення, які лектор давав лише усно, можуть бути не відображені. Для лекції 12 немає презентації (використано сторінку з прикладом workflow і PDF про GitHub Actions).
